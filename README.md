## 🚀 Быстрый старт / Quick Start

```bash
git clone https://github.com/QuadDarv1ne/test-trainer.git
cd test-trainer
npm install
npx prisma db push
npm run dev
```

Приложение доступно по адресу [http://localhost:3000](http://localhost:3000)
