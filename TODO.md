# Рекомендации по улучшению проекта TestTrainer

## 1. Исправление тёмной темы

### Обнаруженные проблемы
- Некоторые компоненты некорректно отображаются на тёмной теме (жестко заданные цвета без `dark:` префиксов)
- Карточки и панели могут иметь недостаточный контраст
- Границы элементов могут быть невидимы
- Текст в некоторых местах сливается с фоном

### Что исправить
- Аудит всех компонентов с жесткими цветами (`bg-white`, `text-black`, `bg-zinc-900` и т.д.)
- Добавить `dark:` префиксы для всех фонов, текста и границ
- Проверить видимость иконок и бейджей на тёмной теме
- Убедиться, что графики и диаграммы читаемы
- Проверить модальные окна и диалоги
- Протестировать hover/active состояния

### Файлы для проверки
- Все компоненты в `src/components/`
- `src/app/globals.css` — CSS переменные темы
- Компоненты графиков (recharts)
- Модальные окна (Dialog, Sheet, AlertDialog)
