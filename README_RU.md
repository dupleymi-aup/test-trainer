## О проекте

**Тренажёр тестирования** — это комплексная веб-платформа для интерактивного изучения методов тестирования программного обеспечения. Проект разработан как полноценное образовательное приложение, объединяющее задачи на классы эквивалентности, граничные значения, систему тестирования с экзаменационным режимом, геймификацию с XP-прогрессией и систему достижений. Платформа предназначена для студентов IT-специальностей, QA-инженеров и всех, кто хочет освоить методы чёрного ящика через практические упражнения.

Проект поддерживает аутентификацию пользователей, сохранение прогресса в базе данных, экспорт результатов и адаптивный интерфейс для всех устройств.

## Ключевые возможности

- **10 интерактивных задач** — от факториала до валидации даты, каждая с классами эквивалентности и граничными значениями
- **Система оценки покрытия** — автоматический расчёт покрытия классов эквивалентности (EC) и граничных значений (BV)
- **Экзаменационный режим** — генерация случайного набора задач с ограничением по времени
- **Практический режим** — свободное прохождение задач с подсказками
- **Timeline попыток** — визуальная история всех попыток с баллами и датами
- **Сравнение с лучшим** — подсветка прогресса относительно лучшей попытки
- **Fill BV / Fill EC** — автоматическое заполнение тест-кейсов для граничных значений и классов эквивалентности
- **Заметки** — персональные заметки к каждой задаче
- **Система достижений** — бейджи за прогресс: от первого теста до перфекциониста
- **Drag & Drop** — перетаскивание тест-кейсов для изменения порядка
- **Undo/Redo** — история изменений с возможностью отката
- **Экспорт прогресса** — сохранение и загрузка прогресса через JSON-файл
- **Аутентификация** — регистрация, вход, восстановление пароля, верификация email
- **Тёмная и светлая тема** с автоматическим определением системных настроек
- **Адаптивный интерфейс** — полностью отзывчивый дизайн для мобильных устройств, планшетов и десктопов

## Задачи платформы

| # | Задача | Сложность | Описание |
|---|--------|-----------|----------|
| 1 | **Факториал** | Легко | Вычисляет факториал целого неотрицательного числа. Проверка переполнения, отрицательных значений и нечисловых типов |
| 2 | **Простое число** | Средне | Проверяет, является ли целое число простым. Граничные значения, большие числа, нелинейные классы эквивалентности |
| 3 | **Калькулятор скидки** | Средне | Применяет скидку к цене. Многофакторное тестирование: цена + процент скидки |
| 4 | **Високосный год** | Легко | Проверяет високосность года по правилам делимости на 4, 100 и 400 |
| 5 | **Треугольник** | Средне | Определяет тип треугольника по трём сторонам: равносторонний, равнобедренный, разносторонний, не треугольник |
| 6 | **Валидация пароля** | Сложно | Проверяет пароль по критериям: длина ≥ 8, заглавные, строчные, цифры, спецсимволы |
| 7 | **Палиндром** | Легко | Определяет, является ли строка палиндромом. Поддержка кириллицы, пробелов, знаков препинания |
| 8 | **Валидация email** | Сложно | Проверяет корректность email-адреса: формат, домен, TLD, допустимые символы |
| 9 | **Римские цифры** | Средне | Конвертирует целое число в римскую цифру (1–3999) |
| 10 | **Валидация даты** | Сложно | Проверяет корректность даты: день, месяц, год, високосные годы, дни месяца |

## Система оценки

Платформа автоматически оценивает каждый набор тест-кейсов по трём метрикам:

| Метрика | Описание |
|---------|----------|
| **Покрытие EC** | Процент покрытых классов эквивалентности |
| **Покрытие BV** | Процент покрытых граничных значений |
| **Корректность** | Процент правильно классифицированных результатов |
| **Общий балл** | Средневзвешенная оценка: (EC + BV + 2 × Корректность) / 4 |

## Установка и запуск

### Предварительные требования

- **Node.js** версии 18 или выше (рекомендуется 20+)
- **npm**, **yarn**, **pnpm** или **bun** в качестве пакетного менеджера

### Установка

```bash
# Клонировать репозиторий
git clone https://github.com/QuadDarv1ne/test-trainer.git
cd test-trainer

# Установить зависимости
npm install

# Инициализировать базу данных
npx prisma db push

# Запустить в режиме разработки
npm run dev
```

Приложение будет доступно по адресу [http://localhost:3000](http://localhost:3000)

### Сборка для продакшена

```bash
# Сборка проекта
npm run build

# Запуск собранного приложения
npm start
```

### Управление базой данных

```bash
# Применить схему к базе данных
npm run db:push

# Сгенерировать Prisma Client
npm run db:generate

# Создать миграцию
npm run db:migrate

# Сбросить базу данных
npm run db:reset
```
