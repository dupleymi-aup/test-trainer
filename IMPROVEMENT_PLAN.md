# TestTrainer — План улучшений v7.0 (5 пунктов)

## 1. Хук useOnClickOutside
Создать `useOnClickOutside` хук для обработки кликов вне элемента (полезно для dropdown, modals, popovers).

## 2. Хук useInterval
Создать `useInterval` хук для безопасного запуска интервалов с возможностью паузы и изменения интервала.

## 3. Хук useWindowSize
Создать `useWindowSize` хук для отслеживания размеров окна браузера (responsive layout).

## 4. Хук useLockBodyScroll
Создать `useLockBodyScroll` хук для блокировки скролла body при открытых модальных окнах.

## 5. Хук useEventListener
Создать `useEventListener` хук для безопасной подписки на DOM/Window события с автоматической очисткой.
